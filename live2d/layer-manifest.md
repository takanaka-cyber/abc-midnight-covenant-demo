## 必須レイヤー

| PSDレイヤー名 | 内容 | 主な変形 |
| --- | --- | --- |
| `body_base` | どの可動マスクにも属さない下地 | 全身スウェイのみ |
| `topwear` | 首下から胸元を含む上衣 | 呼吸、胸部局所スプリング |
| `face` | 肌、鼻、口周辺 | 頭部追従 |
| `eyewhite` | 左右の白目 | まばたき |
| `irides` | 左右の虹彩・瞳孔 | 視線、まばたき追従 |
| `eyelash` | 左右の上まつ毛 | まばたき |
| `eye_close` | 左右の閉じ目 | 閉眼時に表示 |
| `mouth_open` | 開いた口 | 会話時の縦開閉 |
| `mouth_close` | 閉じ口 | 待機時 |
| `front hair` | 前髪、横髪 | 顔より遅いスプリング |
| `headwear` | 角と髪飾り | 頭部追従 |
| `earwear` | 両耳のピアス | 頭部追従 |

## 胸部リグ契約

- 適用先は `topwear` の胸部楕円領域だけ
- 呼吸: 肩を小さく上げ、胸郭を約0.3%だけ横へ広げる
- 独立揺れ: 胸部中心ほど強く、外周ほどゼロへ落ちるガウシアン変形
- 駆動: 呼吸、胴体角度、全身スウェイを入力にした減衰スプリング
- 記事LP初期強度: `3.0`
- 上限: `4.0`
- 首、顔、腹部、タブレットへ変形を漏らさない

## 再合成QA

- 元画像とPSD再合成画像を同寸で比較する
- 目、前髪、胸元、脇、タブレット周辺を拡大確認する
- 欠損や継ぎ目があるレイヤーは、動かす前に下層へ描き足す
